| 页面方法 | 成功条件 | 原生/JS 预算 | 页面级钩子（顺序不变） | 重试守卫 | 最终兜底 / 异常 |
|----------|----------|--------------|------------------------|----------|-----------------|
| InventoryPage.add_to_cart | Remove 按钮可见 | 10s / 5s（ADD_CONFIRM_TIMEOUT） | 刷新 → wait_inventory_loaded → 3s 复核 | 加购按钮仍在 | 采集诊断附件 → TimeoutException「加购[slug]失败…」 |
| InventoryPage.remove_from_cart | 加购按钮恢复可见 | 10s / 5s | 无 | 移除按钮仍在 | TimeoutException「移除[slug]失败…」 |
| InventoryPage.click_product_link | 标题链接不可见（已离开列表页） | 10s / 5s | 无 | 链接计数 > 0 | TimeoutException「点击商品[id]后未离开列表页…」 |
| InventoryPage.open_cart | 当前 URL 含 `/cart.html` | 10s / 5s | 无 | 无条件（与原实现一致） | fallback_url 存在 → open_url 直达并返回；否则 TimeoutException |
| CartPage.click_checkout | Checkout 按钮不可见 | 10s / 5s | 无 | 按钮计数 > 0 | TimeoutException「点击 Checkout 后未离开购物车页…」 |
| CartPage.remove_item | 移除按钮不可见 | 10s / 5s | 刷新 → wait_cart_page_loaded → 5s 复核 | 不重试（retries=0，与原实现一致） | TimeoutException「删除购物车商品[slug]失败…」 |
